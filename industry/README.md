# 行业包

这个站和“行业”有关的一切都在这里。换一个行业，主要就是改这个文件夹，步骤见 [把它改成你的行业](../docs/customize.md)。

当前配置是 MyHOT 中国 A 股 / 财经资讯与题材讨论：保留六分类、七内容类型及原 41 个 `finance-` 主题，新增 10 个细分题材，共 51 个目录入口；产业与关注主题优先，机构和资讯类型辅助。模型榜和 Codex 重置监控关闭，门槛仍为 `60/65/76`、理解下限 50；两个 Gold 示例文件均为虚构格式样例，需另建人工校准集。既有财经 V1 契约见 [财经 V1](../docs/finance-v1.md)。

| 文件 | 内容 |
|---|---|
| `site.ts` | 站名、行业词、首页文案、关于页、备案号 |
| `taxonomy.ts` | 分类、标签、公司与机构、防止模型写错公司的词表 |
| `topics.json` | 主题目录（`/topics`） |
| `hot-topics.ts` | 34 个题材词表与父主题关系；新闻讨论统计窗口和首页 Top5 配置 |
| `sources.json` | 当前为空；不导入示范信源，也不覆盖既有数据库来源 |
| `prompts/` | 每一步的提示词：预筛、评分、写作、结构化、归组、综述、日报、翻译 |
| `selection.ts` | 入选门槛 |
| `features.ts` | 模型榜、Codex 重置监控的开关 |
| `brand/` | 图标、Logo、日报周报月报的报头字 |

## 题材讨论与催化证据

静态目录按标签浏览精选文章，题材讨论榜汇总多个独立事件及讨论信号，两者不共用排序含义。互联网先热但没有事实锚点的材料保留为待核实讨论；同题材不同公司的事件保持独立，不放宽 SAME_OCCURRENCE/SAME_STORY。

`hot-topics.ts` 保留原 24 个关注主题，新增光通信、液冷、半导体设备/材料/先进封装、机器人执行器/传感器、创新药临床/审批/授权。关键词与别名只用于文本关联，不确认事实、上市身份或板块影响。材料匹配细分时不重复计入父主题，词表匹配无关内容时应修正词表和样本，不把误匹配当作模型已验证。

统计沿用 48 小时窗口、24 小时半衰期和近 6 小时比较，首页最多展示 5 项，完整榜单覆盖全部配置题材。计数只代表已接入信源的讨论覆盖，作者身份未核实时不称讨论人数；重复转载、同源多平台和采集扩容不能制造独立支持或升温。第一期没有行情验证，不输出真实涨停、连板、成交额或资金核验，也不推断买卖点、目标价或受益股。

新配置与 Prompt 不自动重评历史文章；主题 seed 保留旧 URL，不删除旧主题。行业源码进入镜像时需要 rebuild，生产 seed 或重评须另行协调授权。

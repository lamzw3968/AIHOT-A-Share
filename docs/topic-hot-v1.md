# MyHOT 题材热点榜 V1

2026-10-08：从广泛财经资讯进一步聚焦短期题材。首页展示全部已统计题材中的 Top5，`/hot` 保留完整榜单，`/hot/topic/:slug` 显示相关报道、讨论链接和独立事件。题材不足五个时不补凑。

## 两条内容流

- `editorial`：继续预筛、独立双评分、写作、事件归组和发布。公开、合格并已到发布时间的材料可作为题材相关报道；不会因为进入题材榜就自动入选精选。
- `hot_signal`：近期讨论直接作关注信号。无需先匹配已有事件，未匹配的财经 `#话题#` 可进入讨论候选池，标为待核实；不为它生成新闻详情或公开正文。
- `isolated`：两条流都不计。回灌、归档材料、未来时间、被撤回的材料不增加当前热度。

题材聚合不创建或合并 story。不同公司、交易、订单和阶段继续保留原来的事件身份。关键词关联只能说明材料谈到这个题材，不能确认某家公司受益、传闻真实或板块已经上涨。

## 行业词表

`industry/hot-topics.ts` 定义 34 个榜单题材、材料标签、别名、关键词及细分父主题。保留原有 24 个关注主题，新增光通信、液冷、半导体设备、半导体材料、先进封装、机器人执行器、机器人传感器、创新药临床、创新药审批、创新药授权。

同一材料命中细分题材时不再重复计入其父题材；兄弟题材可以分别命中。`sourceTags` 仅提供财经语境，不能把来源内的所有材料自动计入该题材。未知讨论候选需要财经语境和明确话题标签，使用 `signal-` 稳定哈希，单材料最多 8 个；不会写进主题目录。

`industry/topics.json` 目录现在有 51 个主题：7 个机构、34 个关注主题、10 个资讯类型。保留全部旧 slug 和旧详情，不修改已有主题的身份。上线时通过既有 seed 同步目录；不会导入新信源。

## 统计口径

当前关注度是**新闻与讨论的来源覆盖代理指标**，不是真实全网人数，也不是经过市场收益校准的因子。

1. 统计原始发布时间，缺失时用发现时间。窗口 48 小时，半衰期 24 小时；每 5 分钟由 worker 的 `topics.rank` 更新。
2. 同一材料 ID 去重；每个配置的独立来源组在每个题材只贡献一次，以它最新材料的时间衰减。组身份依次使用 `signal_group_id`、`owner_entity_id`、来源 ID。不同账号若属于同一机构，运营者需正确配置组；不推测真实作者人数。
3. 关注度为来源组衰减贡献之和乘 10。并列时优先独立讨论组、最近材料时间及稳定 slug。全榜保留所有有材料的题材，页面取前 5。
4. 另外展示讨论条数、近 6 小时新增讨论、独立讨论组、报告数、独立事件数和 URL 主机归一化的平台覆盖。平台包含报道网站，不能冒称全部为社交平台。点赞、阅读、评论量尚未纳入，也不跨平台相加。
5. 趋势比较当前和 6 小时前各自的 48 小时窗口。来源新增、采集落后、输入截断或快照超过 15 分钟时显示未知，不把覆盖变化当成升温。外部推送来源没有采集心跳，不能据此保证推送持续完整。
6. 最多读取近 54 小时的 10,000 条输入。达到上限时明确标示覆盖不完整并停止趋势比较。仅保留最新 288 个衍生快照，避免低配服务器无限增长。

材料状态与关注度分开：第一方材料、报道材料、待核实、有澄清材料、第一方与澄清材料。第一方身份来自来源配置，不等于独立事实核验；“第一方与澄清材料”可能对应不同事件，不能解读为同一事实已经判定真假。澄清标记仅识别第一方标题中的澄清/辟谣/回应与明确否认，普通取消、延期不自动当作辟谣。详情保留原文核查入口。

## 后端和缓存

新增向后兼容迁移 `0042_topic_hot_rankings.sql`，只增加 `topic_hot_rankings`。`events/topic-heat.ts` 是唯一写入者；`publication/topic-hot.ts` 是统一公开读取入口，每次重查当前来源角色、公开状态、链接和发布门槛，不直接公开保存的旧标题或讨论正文。

网站自用 HTTP 接口新增 `/api/site/topic-hot` 和 `/api/site/topic-hot/:slug`。原事件榜、公开 API v1、RSS 和 MCP 协议保持原样；本轮未增加对应的 v1/MCP 工具。新榜的任何后续出口须复用同一 publication 入口。

页面读取不会计算新快照、调用模型或触发采集。缓存截止受下一快照、材料窗口过期和待发布门槛约束，匿名访问一致，支持 ETag。撤回和来源隔离会在当前公开读取中立即过滤，浏览器及代理仍受短缓存的传播延迟约束。

## 本轮边界与后续

没有行情库、证券映射、买卖建议、目标价、确定涨跌预测或“已确认受益股”。`marketDataAvailable=false` 明示未验证涨跌、资金流或涨停数量。既有财经类别、七种内容类型、双评分、60/65/76 门槛及理解门槛 50 不变。

确定性词表可能错配或漏配；未加标签的新题材可能漏掉。人工 Gold Set、真实模型选稿校准、实际讨论源覆盖与可选行情确认均为后续工作。真实采集、模型、通知没有启用；未连接生产、改 `.env`、部署、推送或重评历史文章。升级以后需应用增量迁移、seed 新目录并 rebuild；不能只 restart worker。
